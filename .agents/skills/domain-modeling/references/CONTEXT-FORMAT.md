# CONTEXT.md Format

## Structure

```md
# ParetoPC

{One or two sentence description of what this context is and why it exists.}

## Language

**Term**:
{A one or two sentence mathematical and domain definition of the term}
_Avoid_: Ambiguous synonym 1, Ambiguous synonym 2
```

## Rules

- **Be opinionated.** When multiple words exist for the same concept, pick the canonical one and list the others under `_Avoid_`.
- **Keep definitions tight.** Define what it IS mathematically and in the codebase.
- **Only include terms specific to ParetoPC's MCDM & PC hardware domain.**
