# 05 — Idea bank

> Not a task list. When an idea is picked, it becomes a `TODO.md` item with the task template. Rough effort: S = a day, M = a week, L = a month.

## Getting attention

| Idea | Why it works | Effort |
|---|---|---|
| **"Black Fraude" checker** — paste any deal; see its price history and whether it's on the frontier | Brazilians already joke about fake Black Friday discounts; this gives the joke a tool | M |
| **Monthly Frontier Report** (BR + US) — best value per budget, worst trap of the month | Recurring content creators and press can cite | S/month |
| **"Your PC vs the frontier"** — enter your current PC, see how far from the frontier it was when you bought it | Shareable, a bit of a game, leads into upgrade mode | M |
| **Frontier animation** — a short video of the frontier moving through Black Friday week | Works on TikTok/Reels/Shorts without explaining math | S |
| **Tier list generated from math** (S/A/B/C by distance to the frontier) | Tier lists are the most-watched hardware format | S |
| **"Mario Meets Pareto" style explainer** page for the curious | The project's origin; good for Hacker News and r/dataisbeautiful | S |

## Hard problems, other angles

| Problem | Angle |
|---|---|
| Prices go stale | Let the buyer's own browser be the live data source (paste, bookmarklet, extension); the repo is only the reference |
| Matching store listings to parts | EAN/GTIN first; when the user pastes, ask one question ("is this the 8 GB or 16 GB?") instead of guessing |
| Technology relevance is opinion | Make it a visible, cited table; let creators publish alternative tables; show how the pick changes |
| Beginners vs experts | Same page, two layers: answer card on top, "see why" opens the chart in place; never two separate sites |
| Compatibility edge cases | "Check this yourself" warnings beat silent passes; collect every reported mistake as a test |
| Low commission rates | Earn on repeat visits (price alerts), sponsorship that must pass the frontier test, B2B licensing |
